# અલ્ટરનેટર ડિસમેન્ટલિંગ લેબ · Alternator Dismantling Lab

3D simulator of a 14 V 120 A compact automotive alternator, made for ITI Auto Electrician / MMV / Mechanic Diesel students.
Students take the alternator apart part by part, look inside, run it on a virtual test bench and test it like in a real workshop.

**Languages:** ગુજરાતી · हिंदी · English

## Features

- **Simulator:** 22 removable parts in the real workshop order. Removed parts are laid out on the bench mat.
  - Cut section, X-ray, exploded view, and magnetism (N/S claw poles and flux lines).
  - Live test bench: motor and belt drive, volt / amp / rpm meters, battery, ignition key and charge warning lamp.
  - 9 switchable loads, battery state of charge and 14 simulated faults.
  - Live oscilloscope (3-phase AC, B+ ripple, field PWM), charging-circuit diagram and output-vs-speed curve.
- **Testing lab:** 17 workshop tests (8 on-vehicle, 9 bench) with steps, diagrams, a virtual multimeter and pass/fail.
  - Mystery-fault diagnosis challenge and a test report for the job sheet.
- **Guided demos:**
  - how the alternator works
  - dismantling with tools
  - assembly with torque values
  - optional voice narration
- **Theory** (16 sections, diagrams, formulas, worked examples) and **45 MCQs**.

Figures are typical for this type of alternator, not from a specific maker.

## How to use

Open `index.html` in Chrome, Edge or Firefox. An internet connection is needed, because three.js and the fonts load from a CDN.

To publish it as a website, go to **Settings → Pages**, choose **Deploy from a branch → `main` / root**, and save.
